# 🌲 森活高峰島・校慶運動大冒險 🏃
### 新竹市東區高峰國民小學 22 週年校慶「森活高峰・廿二璀璨」3D 動態互動島

歡迎來到新竹市東區高峰國小（GFPS）22 週年校慶運動會專屬 3D 動態島！
本專案為融合「都市森林小學」自然生態綠意、新竹在地玻璃工藝特色與 GFPS 四大核心願景（Global, Friendly, Positive, SDGs）的沉浸式互動島嶼。

---

## 🌟 核心特色

1. **6 座森林賽場島嶼 ✕ 19 座 3D 互動地標**：
   - **高峰盛典廣場**：聖火引燃、大會司令台、校長表揚親師志工。
   - **玻璃藝能綠律島**：在地玻璃工藝大舞台、各學年大會舞展演。
   - **疾風競速跑道島**：綠茵環形跑道、起跑反應測驗、終點衝刺線。
   - **薪傳接力競技場**：大隊接力交接棒區、親師校友薪傳友誼賽。
   - **森林智慧探索島**：植物園生態趣味闖關、低碳永續自備水壺補給站。
   - **GFPS 榮耀星光島**：星光金牌頒獎台、大會總錦標金盃、全景 3D 勝利煙火！
2. **五力集章護照 ✕ 專屬金牌榮譽證書**：
   - 包含【友善品格力】、【玻璃美感力】、【峰湧體能力】、【高峰群體力】、【全球永續力】五大印章。
   - 題目選項動態洗牌、步驟隨機打散，集滿 5 枚印章即可點燃全景 3D 勝利煙火，並下載專屬 1200×675 高畫質證書！
3. **32 項大會程序表 ✕ 賽前戰報英雄榜**：
   - 完整收錄當日 08:00–13:50 典禮、舞蹈、趣味競賽與徑賽決賽時程。
   - 完整支援三至六年級 60m、100m、200m 個人賽事成績與道次查詢（個資遮罩去識別化保護）。
4. **手機窄螢幕友善**：
   - 支援頂部動態島膠囊快速收合展開。
   - 彈出卡片頂部自適應安全避讓距（56px），解決手機網址列遮擋卡片關閉按鈕問題。
